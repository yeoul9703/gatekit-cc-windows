# gatekit 사용 안내 (Windows + Claude Code)

gatekit은 "만들기 전에 정리하고, 끝났는지 코드로 확인하게" 도와주는 도구입니다.
이 폴더를 Claude Code로 열면 바로 동작합니다. 터미널(검은 창)을 몰라도
됩니다. 필요한 프로그램 설치도 Claude가 물어본 뒤에 대신 해 줍니다.

## 한눈에 보기: 무엇을 어떤 순서로 입력하나

아래 이름을 Claude Code 채팅창에 그대로 입력합니다. 순서를 외울 필요는
없습니다. 한 단계가 끝나면 Claude가 "다음 단계로 갈까요, 여기서 더
손볼까요, 멈출까요?"라고 묻고, 다음으로 가겠다고 하면 다음 단계를 알아서
시작합니다. 멈췄다가 나중에 돌아왔을 때만 아래에서 이어서 할 이름을 찾아
입력하세요.

**① 처음 한 번만**

| 입력 | 하는 일 |
|---|---|
| `/gatekit-setup` | 필요한 프로그램이 있는지 점검하고, 빠진 것은 물어본 뒤 설치합니다 |

**② 무언가를 만들 때, 이 순서대로 (모두 필수)**

| 순서 | 입력 | 하는 일 |
|---|---|---|
| 1 | `/gatekit-interview` | 무엇을 만들지 대화로 정리해 문서로 남깁니다 |
| 2 | `/gatekit-tasks` | 정리한 내용을 작은 작업 목록으로 나눕니다 |
| 3 | `/gatekit-gate` | "어떻게 되면 끝난 것인지" 기준을 정합니다. 내가 승인해야 다음으로 갑니다 |
| 4 | `/gatekit-build` | 작업 목록대로 실제로 만듭니다. 가장 오래 걸리는 단계입니다 |
| 5 | `/gatekit-verify` | 정한 기준대로 다 됐는지 따로 검사합니다 |

**③ 상황에 따라 끼워 넣는 것**

| 입력 | 언제 필요한가 | 어디에 끼우나 |
|---|---|---|
| `/gatekit-discover` | 무엇을 만들지 아직 모를 때 | 1번(interview) 앞 |
| `/gatekit-mockup` | 화면이 있는 것(웹사이트, 앱)을 만들 때. **이 경우에는 필수입니다.** 화면 구성을 정하고, 눌러 볼 수 있는 시안으로 확인받습니다. 건너뛰면 2번(tasks)이 멈추고 이것부터 하라고 알려 줍니다. 화면이 전혀 없는 도구만 생략합니다 | 1번(interview)과 2번(tasks) 사이 |
| `/gatekit-design` | 참고할 사이트나 피그마 파일에서 색, 글꼴, 디자인 규칙을 뽑아 쓰고 싶을 때 | 아무 때나 |

화면이 있는 것을 만든다면 전체 순서는 interview → mockup → tasks → gate →
build → verify 입니다.

**④ 뭔가 이상할 때**

| 입력 | 하는 일 |
|---|---|
| `/gatekit-doctor` | gatekit이 제대로 설치돼 동작하는지 8가지를 점검하고 고치는 방법을 알려 줍니다 |

Claude Code에 원래 있는 `/doctor`는 Claude Code 자체를 점검하고, gatekit 상태는 `/gatekit-doctor`가 점검합니다. 이름이 비슷하니 헷갈리지 마세요.

**build 단계에 대해 미리 알아 둘 것.** 시작하기 전에 Claude가 작업이 몇 개인지
알려 줍니다. 작업이 많으면 오래 걸리고, 쓰고 있는 Claude 요금제의 사용량도
그만큼 씁니다. 사용량 한도에 걸리거나 창을 닫아서 중간에 멈춰도 그때까지의
결과는 저장돼 있습니다. 다시 열어 `/gatekit-build`를 입력하면 아직 통과하지
못한 작업부터 이어서 합니다.

## 1. 필요한 것

| 프로그램 | 꼭 필요? | 설명 |
|---|---|---|
| Claude Code | 예 | 데스크톱 앱, VS Code 확장, 터미널 중 어느 것이든 됩니다 |
| uv | 예 | gatekit이 쓰는 Python을 알아서 준비해 주는 프로그램입니다. 없으면 `/gatekit-setup`이 설치를 제안합니다 |
| PowerShell 7 | 예 | Claude Code가 명령을 실행할 때 씁니다. 미리보기(preview)가 아닌 안정판이 있어야 합니다. 없으면 `/gatekit-setup`이 설치를 제안합니다 |
| winget | 권장 | 설치를 쉽게 해 줍니다. Windows 11에는 보통 들어 있습니다. 없으면 `/gatekit-setup`이 설치를 제안합니다 |
| `claude` 명령(CLI) | 선택 | 없어도 됩니다. 기본 설정에서는 쓰지 않고, build를 워커 방식으로 돌리게 설정했을 때만 필요합니다 |
| Git for Windows | 권장 | 없어도 동작합니다. 있으면 망가진 파일을 되돌릴 수 있고 작업 이력이 남습니다. 없으면 `/gatekit-setup`이 설치를 제안합니다 |

Python은 따로 설치하지 않아도 됩니다. uv가 준비합니다.

## 2. 폴더 열기

1. 이 저장소를 내려받아 압축을 풀거나 `git clone` 합니다.
2. Claude Code에서 `gpters-24th-gate-kit` 폴더(안에 `.claude` 폴더가 있는 폴더)를
   프로젝트로 엽니다.
3. 열 때 "이 폴더를 신뢰하시겠습니까?"라고 물으면, 내용을 확인한 뒤 신뢰를
   선택해야 gatekit의 훅(자동 점검)이 켜집니다.

## 3. 처음 할 일: `/gatekit-setup`

채팅창에 이렇게 입력하세요.

```
/gatekit-setup
```

무엇을 하나요?

- 먼저 **점검만** 합니다. uv, PowerShell 7, 작업용 폴더(`.venv`)가
  준비됐는지 표로 보여 줍니다. `claude` 명령은 없어도 됩니다. 표에 "경고"로
  나오더라도 지금 설정에서는 쓰지 않는다는 안내일 뿐입니다. Git도 없으면
  "경고"로 나오고, 설치할지 함께 물어봅니다(없어도 gatekit은 동작합니다).
- 빠진 것이 있으면 채팅에서 **한 번 물어봅니다.** 전부 설치 / 골라서 설치 /
  나중에. 대답하기 전에는 아무것도 설치하지 않습니다.
- 끝나면 `.gatekit/config.json` 설정 파일을 만들고 마지막에 `doctor`로
  다시 확인합니다.

두 종류의 물음을 헷갈리지 마세요.

- **권한 창** (Claude가 띄우는 팝업): "이 점검을 실행해도 됩니까?"라는 뜻입니다.
  설치 허락이 아닙니다.
- **채팅 질문**: "이 프로그램을 설치해도 됩니까?"입니다. 설치는 여기서
  "예"라고 한 것만 진행됩니다.

설치 뒤에 "Claude Code(데스크톱 앱, VS Code 창, 또는 실행 중인 터미널)를 완전히 닫고
다시 여세요"라고 하면 그대로 하세요.
(방금 설치한 프로그램을 앱이 아직 못 찾는 상태입니다.) 데스크톱 앱은 창을 닫아도
남아 있으니 작업 표시줄 오른쪽 아래(트레이)의 Claude 아이콘에서 종료하세요. 다시 연 뒤
`/gatekit-setup`을 한 번 더 입력하면 됩니다.

Git을 설치할 때는 Windows의 관리자 확인 창이 뜰 수 있습니다. 먼저 관리자 권한이 필요 없는
방식으로 설치해 보고, 안 되면 한 번 더 시도하는데 그때 이 창이 뜰 수 있습니다. 이 창은 다른 창
뒤에 숨기도 하니, 설치가 멈춘 것 같으면 작업 표시줄에서 깜박이는 아이콘을 눌러 보세요.

## 4. 명령 목록

모두 채팅창에 `/gatekit-<이름>`으로 입력합니다. "기획해줘", "빌드 시작해줘"
처럼 말해도 알아듣습니다.

| 명령 | 하는 일 |
|---|---|
| `/gatekit-setup` | 처음 준비 (위 3번) |
| `/gatekit-discover` | 뭘 만들지 모를 때, 대화로 문제를 찾습니다 |
| `/gatekit-interview` | 아이디어를 요구사항 문서(PRD)와 구조 문서로 정리합니다 |
| `/gatekit-mockup` | 화면 명세를 만들고 시안으로 확인받습니다. 피그마·HTML·스크린샷이 있으면 그것을 읽습니다 |
| `/gatekit-design` | 참고 사이트나 프리셋에서 디자인 규칙을 뽑습니다 |
| `/gatekit-tasks` | 스펙을 작업 목록으로 쪼갭니다 |
| `/gatekit-gate` | "언제 끝난 건지"를 확인 가능한 기준으로 정합니다 |
| `/gatekit-build` | 작업을 실행합니다. 통과/실패는 게이트가 판정합니다 |
| `/gatekit-verify` | 다 됐다는 주장을 독립적으로 다시 검증합니다 |
| `/gatekit-doctor` | 설치 상태를 점검합니다 |

순서는 맨 위 "한눈에 보기"에 있습니다. `mockup`은 화면이 있는 것을 만들 때는
건너뛸 수 없고, `discover`와 `design`은 필요할 때만 씁니다.

## 5. 문제가 생겼을 때

**세션을 시작할 때 경고가 뜬다.** uv나 `.venv`, PowerShell 7이 없다는 뜻입니다.
(build를 워커 방식으로 돌리게 설정한 프로젝트에서는 `claude` 명령이 없을 때도 뜹니다.)
이 상태에서는 gatekit의 자동 점검이 조용히 꺼져 있습니다. `/gatekit-setup`을
입력하세요.

**`/gatekit-doctor`를 실행해 본다.** 아래 8가지를 점검하고, 고치는 방법도 알려
줍니다.

1. 필요한 파일이 다 있는가
2. 훅이 등록돼 있고, `.claude/settings.json`에 PowerShell 설정 두 가지가 있는가
3. 프로젝트 상태 파일(`.gatekit/`)이 올바른가
4. 스펙 문서 묶음이 올바른가
5. 완료 기준이 최신인가
6. 작업자(`claude` 명령)가 응답하는가. 기본 설정에서는 쓰지 않으므로 없어도 통과입니다
7. Python(3.14 이상)이 준비됐는가
8. uv가 있는가

"확인 못 함(unverified)"은 "아직 검사할 대상이 없다"는 뜻이며, 통과가 아닙니다.
새 프로젝트에서는 스펙이 없어서 흔히 나옵니다.

**아무 반응이 없다.** 훅이 내부 오류를 내도 Claude 세션이 멈추지는 않습니다.
대신 원인이 한 줄씩 이 파일에 남습니다.

```
.gatekit/runs/hook-errors.log
```

**회사 PC라서 설치가 막힌다.** 회사 보안 정책이나 네트워크가 winget·다운로드를
막을 수 있습니다. `/gatekit-setup`이 "정책·네트워크로 불가"라고 알려 주면,
표시된 안내문을 IT 담당자에게 전달하세요. 우회하려고 하지 마세요.

**PowerShell 7이 있는데 없다고 나온다.** 미리보기(preview)만 설치돼 있으면 설치된 것으로 치지
않습니다. setup이 안정판 설치를 제안합니다. 안정판과 preview가 함께 있는 것은 괜찮습니다.

**설치가 실패했거나 uv를 다시 설치하고 싶다.** 도구별 설치·업데이트·재설치 명령,
winget이 없을 때 설치하는 방법, PowerShell 7 안정판 판정 방법, winget 오류 코드 표, IT 담당자 문의문, CLI가 안 될 때 스크립트를 직접 실행하는 방법은
[설치·업데이트·재설치 참조](SETUP-REFERENCE.md)에 있습니다.

**설치했는데 못 찾는다.** Claude Code(데스크톱 앱, VS Code 창, 또는 실행 중인 터미널)를 완전히 닫고 다시 연 뒤
`/gatekit-setup`을 다시 입력하세요. 데스크톱 앱은 창을 닫아도 남아 있으니 작업 표시줄 오른쪽 아래(트레이)의
Claude 아이콘에서 종료해야 완전히 닫힙니다.

**폴더가 OneDrive 안이거나 경로가 너무 길다.** setup이 경고합니다. `C:\dev`
같은 짧은 경로로 옮기면 대부분 해결됩니다.

그래도 안 되면 이슈를 남겨 주세요.
